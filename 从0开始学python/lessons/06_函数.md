# 第 06 章：函数

> 本章目标：学会把代码打包成函数。**函数是编程世界的"积木"**——一个模型就是一个会算东西的函数。

## 1. 定义与调用

```python
def greet(name):                 # def 定义函数；name 是参数
    """向指定的人打招呼"""         # 文档字符串：说明函数干什么（可省略但推荐写）
    print(f"你好, {name}!")

greet("GPT")                     # 调用：传入"GPT" → 你好, GPT!
greet("LLM")                     # 再调用一次——这就是复用
```

语法要点：`def 函数名(参数):` + 缩进的函数体。函数**定义时不执行**，调用时才执行。

## 2. return：把结果交出来

`print` 只是给人看，`return` 才是把结果交给程序继续用：

```python
def add(a, b):
    return a + b

result = add(3, 5)          # result = 8，可以继续参与运算
print(result * 2)           # 16
```

- 没写 return 的函数返回 `None`
- `return` 立刻结束函数（可用来提前退出）

### 返回多个值（其实是元组+解包）

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4, 1, 5])     # 解包接收
print(low, high)                          # 1 5
```

## 3. 参数的四种玩法

### 3.1 位置参数：按顺序对号入座

```python
def power(base, exp):
    return base ** exp

print(power(2, 10))         # 1024，2给base、10给exp
```

### 3.2 关键字参数：指名道姓

```python
print(power(exp=10, base=2))   # 1024，指名后顺序随意
```

### 3.3 默认参数：不传就用默认值

```python
def train(epochs=10, lr=0.001):
    print(f"训练{epochs}轮, 学习率{lr}")

train()                     # 训练10轮, 学习率0.001（全用默认）
train(epochs=100)           # 只改一个
train(100, 0.01)            # 按位置覆盖（顺序必须对）
```

⚠️ 经典大坑：**默认值不要用列表/字典**（可变对象只创建一次，多次调用会共享）：

```python
def bad(item, box=[]):      # ❌ 所有调用共享同一个box！
    box.append(item)
    return box

def good(item, box=None):   # ✅ 正确写法
    if box is None:
        box = []
    box.append(item)
    return box
```

### 3.4 *args / **kwargs：接收任意多参数

```python
def summary(*args, **kwargs):
    print("位置参数打包成元组:", args)
    print("关键字参数打包成字典:", kwargs)

summary(1, 2, 3, lr=0.01, epochs=5)
# 位置参数打包成元组: (1, 2, 3)
# 关键字参数打包成字典: {'lr': 0.01, 'epochs': 5}
```

读 PyTorch 源码会大量见到 `def forward(self, *args, **kwargs)`——就是"什么参数都收"。

## 4. 作用域：变量在地盘里才有效

函数内部创建的变量是**局部变量**，外面看不见：

```python
def f():
    x = 10          # 局部变量
    print(x)

f()
# print(x)          # ❌ 报错！x只在f内部存在

lr = 0.1            # 全局变量
def g():
    print(lr)       # ✅ 函数内可以"读"全局变量

def h():
    # lr = 0.2      # 这样写是在函数里创建了一个新的局部lr，不是改全局！
    print(lr)
```

原则：**函数内不要改全局变量**（要用 `global` 声明，但这是坏习惯）。需要什么，通过参数传进去；产出什么，用 return 传出来。

## 5. 函数是一等公民：能赋值、能当参数

```python
def relu(x):
    return max(0, x)

f = relu                # 函数可以赋给变量（注意没有括号！）
print(f(-3), f(5))      # 0 5

# 函数可以当参数传 —— 这就是"高阶函数"
def apply(func, values):
    return [func(v) for v in values]

print(apply(relu, [-2, -1, 0, 1, 2]))   # [0, 0, 0, 1, 2]
```

`relu` 是神经网络的激活函数——你看，它就是个普通的 Python 函数。

## 6. lambda：一行的小函数

```python
square = lambda x: x * x        # lambda 参数: 表达式
print(square(9))                 # 81

# 最常见的用法：作为 sorted 的 key
models = [("gpt", 175), ("llama", 65), ("qwen", 7)]
models_by_size = sorted(models, key=lambda m: m[1])
print(models_by_size)            # [('qwen', 7), ('llama', 65), ('gpt', 175)]
```

复杂逻辑别硬塞 lambda，老老实实 `def`。

## 7. 递归：函数调用自己（了解）

```python
def factorial(n):
    if n <= 1:                 # 递归出口（必须有，否则无限调用）
        return 1
    return n * factorial(n - 1)

print(factorial(5))    # 120
```

Transformer 里没有明显递归，但看懂数学公式代码化需要这个思维。

## 8. 大模型视角 🤖

神经网络的每一层都是函数，整个模型是**函数的嵌套调用**：

```python
# 伪代码：y = softmax(W2 · relu(W1 · x + b1) + b2)
def model(x):
    h = relu(linear1(x))       # linear1、relu、linear2 都是函数
    return softmax(linear2(h))
```

- `loss_fn(pred, target)`、`optimizer.step()`——全是函数调用
- 默认参数 = 超参数的默认值（`lr=0.001`）
- `*args/**kwargs` = 框架接口的通用入口

## 本章小结

- `def 名(参数):` 定义；`return` 交出结果；不 return 得到 None
- 参数四种：位置、关键字、默认、`*args/**kwargs`
- 默认值别用可变对象；函数内别改全局变量
- 函数可赋值、可传参（高阶函数）、lambda 写一行小函数

## 练习

1. 写函数 `is_even(n)`，偶数返回 True；测试 7 和 10。
2. 写函数 `tokenize(text)`，把英文句子按空格切小写单词列表（`"Hello World"` → `["hello","world"]`）。
3. 写函数 `count_tokens(tokens)`，返回 `(总数, 去重数)` 两个值（提示：元组）。
4. 写函数 `clip(x, lo=0.0, hi=1.0)`，把 x 限制在 [lo, hi]（梯度裁剪就是它！）。测试 `clip(5)`、`clip(-1)`、`clip(3, hi=2)`。
5. 用 `sorted` + lambda 按 loss 从小到大排：`[("a",0.3),("b",0.1),("c",0.2)]`。

---

### 参考答案

```python
# 1
def is_even(n):
    return n % 2 == 0
print(is_even(7), is_even(10))     # False True

# 2
def tokenize(text):
    return text.lower().split()
print(tokenize("Hello World"))     # ['hello', 'world']

# 3
def count_tokens(tokens):
    return len(tokens), len(set(tokens))
total, unique = count_tokens([5, 5, 8, 9])
print(total, unique)               # 4 3

# 4
def clip(x, lo=0.0, hi=1.0):
    return max(lo, min(hi, x))     # 先压上限，再抬下限
print(clip(5), clip(-1), clip(3, hi=2))   # 1.0 0.0 2

# 5
runs = [("a", 0.3), ("b", 0.1), ("c", 0.2)]
print(sorted(runs, key=lambda r: r[1]))   # [('b', 0.1), ('c', 0.2), ('a', 0.3)]
```
