# 第 03 章：运算符与字符串

> 本章目标：会算数、会比较、会逻辑判断；熟练操作字符串——大模型时代"文本就是数据"。

## 1. 算术运算符

```python
print(7 + 3)    # 10   加
print(7 - 3)    # 4    减
print(7 * 3)    # 21   乘
print(7 / 3)    # 2.3333333333333335  除（结果永远是float）
print(7 // 3)   # 2    整除（向下取整的商）
print(7 % 3)    # 1    取余（模）—— 7 = 2*3 + 1
print(2 ** 10)  # 1024 幂 —— 注意不是 ^，^ 是位运算异或！
```

`//` 和 `%` 在处理序列位置时极其常用。例如句子有 10 个 token，batch 大小是 4：

```python
n_tokens, batch_size = 10, 4
print(n_tokens // batch_size)   # 2 —— 能切出2个完整batch
print(n_tokens % batch_size)    # 2 —— 剩下2个token
```

## 2. 比较运算符：结果是 bool

```python
print(3 > 2)     # True
print(3 == 3)    # True   相等是两个等号！一个等号是赋值
print(3 != 3)    # False  不等
print("a" == "a")  # True  字符串也能比较
```

⚠️ 头号新手错误：`if x = 5:` 报错，判断相等必须 `==`。

## 3. 逻辑运算符：and / or / not

```python
loss = 0.05
epoch = 10
print(loss < 0.1 and epoch > 5)   # True  并且：两边都真才真
print(loss > 0.1 or epoch > 5)    # True  或者：一边真就真
print(not (loss < 0.1))           # False 取反
```

记忆：`and` 要求苛刻（都要满足），`or` 要求宽松（满足一个就行）。

## 4. 复合赋值：+= 一家

```python
total = 0
total += 5    # 等价于 total = total + 5
total *= 2    # 等价于 total = total * 2 → 现在 total 是 10
```

训练时累加总 loss 就靠 `total_loss += loss`。

## 5. 字符串详解

### 5.1 拼接与重复

```python
a = "大"
b = "模型"
print(a + b)        # 大模型    + 拼接
print(a * 3)        # 大大大    * 重复
print("-" * 20)     # --------------------  常用来画分隔线
```

数字和字符串不能直接相加：`"共" + 42` ❌，要 `"共" + str(42)` ✅（下一节的 f-string 更优雅）。

### 5.2 索引与切片（重点！）

字符串是字符组成的序列，每个字符有编号，**从 0 开始**：

```python
s = "transformer"
#    0123456789...   （编号从0开始数）
print(s[0])       # t    第0个
print(s[-1])      # r    倒数第1个（负数从后往前数）
print(len(s))     # 11   长度
```

**切片** `s[起:止]`：取编号 `[起, 止)` 的片段——**含头不含尾**：

```python
print(s[0:6])     # trans   取编号0~5
print(s[:6])      # trans   开头省略=从头开始
print(s[6:])      # former  结尾省略=取到末尾
print(s[-6:])     # former  最后6个字符
print(s[::2])     # tasomr  每隔2个取1个（t_a_s_o_m_r）
```

切片不会报错越界：`s[0:100]` 安静地返回整个字符串。
**切片写法第 14 章会原封不动出现在 NumPy 张量上（如 `logits[:, -1, :]`），现在练熟。**

### 5.3 常用方法（方法=带点号的函数，第11章讲原理）

```python
s = "  Hello World  "
print(s.strip())            # "Hello World"      去掉两端空白
print(s.lower())            # 全转小写
print(s.replace("World", "LLM"))   # 替换
print("a,b,c".split(","))   # ['a', 'b', 'c']    按逗号切开 → 得到列表
print("-".join(["a", "b"])) # "a-b"              用-把列表连成字符串
print("llm" in "large language model".replace("language", "llm"))  # True  in判断包含
```

`split` 和 `join` 是一对互逆操作：切开后是列表（下一章主角），列表能用 join 粘回去。

### 5.4 f-string：现代格式化（必会！）

字符串前加 `f`，里面用 `{}` 塞变量或表达式：

```python
epoch, loss = 7, 0.123456
print(f"第{epoch}轮, loss={loss}")          # 第7轮, loss=0.123456
print(f"loss={loss:.2f}")                   # loss=0.12       保留2位小数
print(f"进度={7/10:.1%}")                   # 进度=70.0%      百分比格式
print(f"参数量={175000000000:,}")           # 参数量=175,000,000,000  千分位
print(f"{epoch=}")                          # epoch=7         调试神器
```

训练日志全靠它：`print(f"epoch {epoch} | loss {loss:.4f}")`。其他老式格式化（`%s`、`.format`）看得懂即可，自己写一律用 f-string。

### 5.5 字符串不可变

```python
s = "hello"
# s[0] = "H"      # ❌ 报错！不能原地修改
s = "H" + s[1:]   # ✅ 只能造一个新字符串
```

## 6. 大模型视角 🤖

- 训练数据第一步就是文本清洗：`strip` 去空白、`lower` 统一大小写、`replace` 去除乱码
- 简易分词（英文）就是 `text.split()`；词表统计就是遍历字符/单词
- 训练日志、实验记录，全靠 f-string 输出得又清楚又整齐

## 本章小结

- `/` 得 float，`//` 整除，`%` 取余，`**` 幂
- `==` 判相等，`and/or/not` 组合条件
- 切片 `[a:b]` 含头不含尾，负数从尾数起，`[::步长]`
- `split` 切、`join` 粘、`strip` 去空白、`in` 查包含
- 永远用 f-string 做格式化

## 练习

1. 计算 2 的 20 次方；再算 100 除以 7 的商（整数）和余数。
2. `s = "machine learning"`：取出 `"machine"`、`"learning"`、最后一个字符、倒数 8 个字符。

4. 用 f-string 打印：`第3轮/共10轮, loss=0.05237 → 显示为 0.0524`（4位小数）。
5. 把 `"gpt, bert, llama"` 按逗号切成列表，再把列表用 `" -> "` 连成一个字符串。
