## 1. 神经网络到底在干什么（一段直觉）

一个神经网络就是一个**带很多可调旋钮的函数** `f(x; W)`：
- `x` 是输入，`W` 是旋钮（参数/权重），一开始随便拧
- 拿一批"题目+标准答案"，让它算 `f(x)`，对比标准答案得到**误差（loss）**
- 关键一步：**对每个旋钮，算出"往哪个方向拧、误差会变小"**——这就是**梯度**
- 每个旋钮朝那个方向拧一点点（**学习率**控制拧多少）
- 重复几千次，误差越来越小——**它"学会"了**

"算梯度"用的是链式法则——**反向传播（backward）**；"拧旋钮"叫**优化（optimizer.step）**。

## 3. 逐段精读（对照 `project/pure_python_net.py`）

### 3.1 Linear 层：前向和反向

前向就是加权求和（第 3、7 章的推导式）：

```python
def forward(self, x):
    self.x = x                        # 缓存输入！反向要用
    return [sum(x[i] * self.W[i][j] for i in range(self.in_dim)) + self.b[j]
            for j in range(self.out_dim)]
```

反向传播要回答三个问题：**误差对 W、对 b、对 x 分别有多敏感？**
设 `y_j = Σ_i x_i·W_ij + b_j`，上游传来 `grad_out[j] = dLoss/dy_j`，由链式法则：

- `dLoss/dW_ij = dLoss/dy_j · dy_j/dW_ij = grad_out[j] · x_i`   → 代码 `gW[i][j] += x[i] * grad_out[j]`
- `dLoss/db_j = grad_out[j] · 1`                                 → 代码 `gb[j] += grad_out[j]`
- `dLoss/dx_i = Σ_j grad_out[j] · W_ij`（要传给前一层）          → 代码返回值

三行公式，三行代码，一一对应。**这就是反向传播的全部秘密，没有更多了。**

### 3.2 Tanh：为什么需要激活函数

如果没有激活函数，两个 Linear 叠起来仍是线性函数（`W2(W1x+b1)+b2` 还是 `Wx+b`），永远学不会 x² 这种弯曲的东西。tanh 把直线"掰弯"。它的导数是 `1 - tanh²`，所以 backward 是 `g * (1 - out²)`。

### 3.3 MSELoss：误差与它的导数

`loss = mean((pred - target)²)`，对 pred 求导得 `2·(pred - target)/n`。`backward()` 返回的就是这个——**反向传播的起点**。

### 3.4 SGD：拧旋钮

```python
W[i][j] -= lr * gW[i][j]     # 沿梯度反方向（误差减小的方向）走 lr 那么远
```

`zero_grad` 为什么必须有？因为 `backward` 里用的是 `+=`（累加），不清零上一步的梯度会叠进来。**PyTorch 也一样，忘写 `zero_grad()` 是新手头号 bug。**

### 3.5 Sequential 与反向传播的方向

```python
def forward(self, x):
    for layer in self.layers: x = layer.forward(x)          # 从前往后
def backward(self, grad):
    for layer in reversed(self.layers): grad = layer.backward(grad)   # 从后往前！
```

`reversed` 就是"反向"两个字的字面意思：梯度从 loss 出发，逆着数据流动的方向一层层传回去。

### 3.6 训练循环：五个步骤，背下来

```python
for epoch in range(epochs):
    for 每个样本:
        opt.zero_grad()                  # ① 清零梯度
        pred = model(x)                  # ② 前向传播
        loss = loss_fn.forward(pred, y)  # ③ 算损失
        model.backward(loss_fn.backward())  # ④ 反向传播
        opt.step()                       # ⑤ 更新参数
```

**你以后写的每一个 PyTorch 训练脚本，核心都是这五行**（PyTorch 里第④步写成 `loss.backward()`）。

## 4. NumPy 版：把 for 循环换成矩阵（对照 `project/numpy_net.py`）

| 纯 Python | NumPy | 说明 |
|---|---|---|
| `sum(x[i]*W[i][j] for i)` 的双重推导 | `x @ self.W + self.b` | 一行矩阵乘 + 广播 |
| `gW[i][j] += x[i]*g[j]` 双重 for | `self.x.T @ grad_out` | `(in,N)@(N,out)=(in,out)` |
| `gb[j] += g[j]` | `grad_out.sum(axis=0)` | 沿样本维度求和（第14章 axis） |
| 一次一个样本 | 一次 200 个样本（batch） | 输入 shape `(N, 1)` |
| 3.3 秒学 x² | 0.5 秒学更难的 sin(x) | 向量化的威力 |

**读懂 `self.x.T @ grad_out` 为什么等于双重 for 循环，是本章最有价值的思考题。** 提示：矩阵乘法的定义就是"对中间维度求和"，这里中间维度是样本数 N——相当于把 N 个样本的梯度加在一起。

## 5. 这和训练大模型有什么关系？

把本项目"升级"成 GPT，需要换的零件：

| 本项目 | GPT / 大模型 |
|---|---|
| 输入：一个数 x | 输入：一串 token 编号（第 5 章的 `list[int]`） |
| `Linear → Tanh → Linear` | 几十层 `Attention + MLP`（MLP 就是 Linear+激活+Linear！） |
| 参数：几十个 | 参数：几十亿个（同样是 float，第 2 章） |
| `MSELoss` | 交叉熵损失（预测下一个 token 的概率） |
| `SGD` | `AdamW`（SGD 的加强版） |
| 手写 backward | 自动求导（`loss.backward()`） |
| 数据在内存里 | 生成器/DataLoader 流式读（第 12 章） |
| **训练循环五步** | **一模一样** |

**语法层面你已经全部具备**。剩下的是数学（注意力机制、交叉熵）和工程（GPU、并行、混合精度）——那是《从0开始学大模型》的内容。
