# 第 13 章：类型注解与代码风格

> 本章目标：学会读写类型注解。**PyTorch 和 HuggingFace 的源码、文档、IDE 提示全是注解**——这是从"会写"到"会读别人的库"的桥梁。本章很轻松。

## 1. 为什么需要类型注解

Python 本身不强制类型，但大项目全都写注解，因为：
1. **读代码快**：看签名就知道要传什么
2. **IDE 智能提示**：VS Code 靠注解给你自动补全、查错
3. **文档即代码**：HuggingFace 文档里的签名就是注解

## 2. 基本注解

```python
# 变量：名字: 类型 = 值
epochs: int = 10
lr: float = 3e-4
name: str = "mini-gpt"
use_gpu: bool = True

# 注错了也不报错！Python 运行时忽略注解（它们是"给人看的"）
epochs: str = 10        # 照样能跑（但IDE会标黄提醒你）
```

### 函数注解

```python
def train(model: str, epochs: int = 10, lr: float = 1e-3) -> bool:
    """参数: 类型，返回值写在 -> 后面"""
    print(f"训练{model} {epochs}轮")
    return True

def tokenize(text: str) -> list[str]:        # 返回字符串列表
    return text.lower().split()
```

读法：`-> bool` 表示"这个函数返回布尔值"。

## 3. 容器类型注解

```python
from typing import Optional, Union

# 内置泛型（Python 3.9+ 直接用小写）
tokens: list[int] = [1, 2, 3]
vocab: dict[str, int] = {"我": 0}
shape: tuple[int, int] = (2, 3)
names: set[str] = {"gpt", "llm"}
matrix: list[list[float]] = [[1.0, 2.0], [3.0, 4.0]]

# 嵌套读法：list[dict[str, float]]
#           = "一个列表，里面每个元素是字典，字典的键是str、值是float"
results: list[dict[str, float]] = [
    {"loss": 0.5},
    {"loss": 0.3},
]

# Optional：可以是某类型，也可以是None
best_loss: Optional[float] = None            # 等价于 float | None（3.10+新写法）

# Union：多选一
config: Union[str, dict] = {}                # 等价于 str | dict
```

## 4. 读懂真实库的签名（实战！）

现在你已经能读懂这些了：

```python
# torch.nn.functional（节选改写）
def linear(input: Tensor, weight: Tensor, bias: Optional[Tensor] = None) -> Tensor: ...
#  → input和weight必须给Tensor，bias可以不给（默认None），返回Tensor

# transformers（节选改写）
def from_pretrained(
    pretrained_model_name_or_path: str,
    torch_dtype: Optional[str] = None,
    device_map: Optional[str | dict] = None,
) -> PreTrainedModel: ...
#  → 只有一个必填参数，其余都可不给，返回一个模型对象

# 自定义Dataset
class MyDataset:
    def __getitem__(self, index: int) -> dict[str, Tensor]: ...
    def __len__(self) -> int: ...
```

**读签名 = 会用一半的库**。以后看不懂某个函数怎么用，先去看它的类型注解。

## 5. typing 进阶（能认脸即可）

```python
from typing import Callable, Iterable, Any, TypeAlias

Callable[[int, int], int]        # 参数(int,int)、返回int的函数类型
Iterable[str]                    # 任何能被for遍历的字符串集合
Any                              # 任意类型（等于没说，尽量少用）

# 类型别名：给复杂类型起名
Batch: TypeAlias = list[list[int]]       # 以后写 Batch 就代表 list[list[int]]

def collate(batch: Batch) -> list[int]:  # 签名立刻清晰了
    return [tok for seq in batch for tok in seq]
```

## 6. 注解怎么被检查：mypy（了解）

注解运行时不生效，想真检查用工具：

```
python -m pip install mypy
python -m mypy your_script.py
```

大项目在 CI 里跑 mypy；自己练习时靠 VS Code 的提示就够。

## 7. 代码风格：PEP 8 速成

不用背，装个格式化工具自动搞定：

- **VS Code**：装 Python 扩展 → 右键"使用 Black 格式化" → 设置"保存时格式化"
- **命令行**：`python -m pip install black` → `python -m black 文件.py`

手动写时记住 5 条就够：
1. 缩进 4 空格（别用Tab）
2. 变量/函数名：`snake_case`；类名：`CamelCase`；常量：`UPPER_CASE`
3. 运算符两边加空格：`a + b`，`f(x, y)` 逗号后空格
4. 一行别超 ~100 字符
5. import 顺序：标准库 → 第三方库 → 自己的模块，三组之间空行

## 本章小结

- `x: 类型 = 值`、`def f(a: int) -> str:`；运行时不强制，给人和IDE看
- 容器：`list[int]` / `dict[str, int]` / `Optional[float]`（= `float | None`）
- 读库先读签名：必填什么、可选什么、返回什么
- 格式交给 black；命名按 PEP 8

## 练习

1. 给函数加注解：`def area(r): return 3.14159 * r * r`（r 和返回值都是 float）。
2. 注解 `batch`（list[list[int]]）、`vocab`（dict[str, int]）、`name_or_none`（str 或 None）。
3. 写注解齐全的函数 `top_k(scores: list[float], k: int = 5) -> list[int]`，返回分数最大的 k 个下标（按分数从大到小）。
4. 读懂并用自己的话说出这个签名要求传什么：`def create_model(config: dict[str, Any], device: Optional[str] = None) -> nn.Module`。
5. 定义类型别名 `Sample = dict[str, list[int]]`，并写函数 `get_input_ids(s: Sample) -> list[int]` 取出 `"input_ids"` 键。

### 参考答案

```python
# 1
def area(r: float) -> float:
    return 3.14159 * r * r

# 2
batch: list[list[int]] = [[1, 2], [3]]
vocab: dict[str, int] = {"我": 0}
name_or_none: str | None = None      # 或 Optional[str]

# 3
def top_k(scores: list[float], k: int = 5) -> list[int]:
    """返回分数最大的k个下标，按分数降序"""
    order = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)
    return order[:k]
print(top_k([0.1, 0.9, 0.5, 0.7], 2))    # [1, 3]

# 4
# 必须传一个字典config（键是str、值任意）；device可选（None或字符串，如"cuda"）；
# 返回一个nn.Module对象（即模型实例）。

# 5
from typing import Any, TypeAlias
Sample: TypeAlias = dict[str, list[int]]

def get_input_ids(s: Sample) -> list[int]:
    return s["input_ids"]
```
