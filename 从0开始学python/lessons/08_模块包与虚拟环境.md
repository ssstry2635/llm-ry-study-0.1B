## 1. import 的三种姿势

模块（module）= 一个 `.py` 文件；包（package）= 一个文件夹（里面常有自己的多个 .py）。

```python
import math                      # 姿势1：整个导入
print(math.sqrt(2))              # 用的时候带前缀 math.

from math import sqrt, pi        # 姿势2：只导入需要的，直接用
print(sqrt(2), pi)

import numpy as np               # 姿势3：导入并起别名（约定俗成的名字别乱改）
print(np.array([1, 2]))
```

别名约定（全世界都这么写，照抄即可）：
`import numpy as np`、`import torch`、`import matplotlib.pyplot as plt`、`from transformers import AutoModel`。

## 2. 常用标准库（Python 自带，不用安装）

```python
import math
print(math.sqrt(9), math.log(math.e), math.exp(1))   # 开方/自然对数/e指数

import random
random.seed(42)                        # 固定随机种子 → 结果可复现（科研必备！）
print(random.random())                 # [0,1) 随机小数
print(random.randint(1, 6))            # 随机整数（含两端）
print(random.choice(["gpt", "llama"])) # 随机挑一个
# 注意：random 只用于模拟/抽样/打乱数据；生成密码或密钥请用 secrets 模块
print(random.shuffle([1,2,3]) or [1,2,3])  # 原地打乱（返回None，注意！）

import os
print(os.getcwd())                     # 当前工作目录
print(os.path.exists("README.md"))     # 文件/文件夹是否存在
print(os.path.join("data", "train.txt"))  # 拼路径（自动处理斜杠）→ data\train.txt

import sys
print(sys.version)                     # Python版本
sys.path.append("/my/libs")            # 让Python能找到自定义库（少见但有用）

import time
t0 = time.time()                       # 当前时间戳（秒）
time.sleep(0.5)                        # 睡0.5秒
print(f"耗时 {time.time() - t0:.3f}秒") # 计时——训练脚本量速度必备

from collections import Counter
print(Counter("abracadabra"))          # 自动计数 → Counter({'a': 5, ...})
print(Counter("abracadabra").most_common(2))   # 最常见的2个 → [('a',5),('b',2)]
```

`Counter` 一行顶你手写的计数循环，统计词频神器。

## 3. 自己写模块

同目录下建 `mymath.py`：

```python
# mymath.py
def sigmoid(x):
    """把任意实数压到(0,1)——神经网络常用激活函数"""
    return 1 / (1 + math.exp(-x))
```

在同目录的另一个文件里就能 `import mymath` 然后用它。
**规则：import 的名字 = 文件名（去掉.py）**。这解释了为什么文件名不能有中文和空格。

## 4. `if __name__ == "__main__":` —— 模块的"开关"

```python
# mymath.py
def sigmoid(x):
    return 1 / (1 + math.exp(-x))

if __name__ == "__main__":
    # 这里的代码只在【直接运行本文件】时执行
    # 被别人 import 时不会执行
    print("自测:", sigmoid(0))     # 0.5
```

原理：直接运行时 Python 把 `__name__` 设成 `"__main__"`；被导入时设成模块名 `"mymath"`。
**所有正式脚本（包括 train.py）都该有这个开关**：文件既能当库被导入，又能当脚本运行。

## 6. 虚拟环境 venv：项目的"独立沙箱"

为什么需要：项目A要 numpy 1.x，项目B要 2.x，装在同一个地方必炸。
虚拟环境 = 每个项目一套独立的库。

```
# 在项目文件夹里执行一次：
python -m venv .venv

# 激活（Windows CMD）：
.venv\Scripts\activate
# 激活（Git Bash / Linux / Mac）：
source .venv/Scripts/activate

# 激活成功后命令行前面出现 (.venv)，之后的 pip install 都只装进这个沙箱
# 退出：deactivate
```

**你上级目录的《从0开始学大模型》项目就该这样做**：进入那个文件夹 → `python -m venv .venv` → 激活 → 装 requirements.txt 里的库。

## 7. requirements.txt：把环境写下来

```
# 导出当前环境（给别人的装机清单）：
python -m pip freeze > requirements.txt

# 别人一键安装：
python -m pip install -r requirements.txt
```
