# 第 07 章：推导式与常用内置函数

> 本章目标：学会"Pythonic"的写法——用推导式一行顶十行。写得短不是炫技，是**思路的压缩**。

## 1. 列表推导式：for 循环的极简形态

需求：把 `[1, 2, 3]` 每个数平方。三代的写法：

```python
nums = [1, 2, 3, 4, 5]

# 初学者写法（对，但啰嗦）
squares = []
for n in nums:
    squares.append(n * n)

# 列表推导式（推荐）
squares = [n * n for n in nums]              # [1, 4, 9, 16, 25]

# 读法：[表达式 for 变量 in 序列]
# 意思是：对nums里的每个n，算n*n，收集成列表
```

### 带条件过滤

```python
evens = [n for n in nums if n % 2 == 0]      # [2, 4]
# [表达式 for 变量 in 序列 if 条件]  —— 条件在前，if 在后
```

### 带条件表达式（if-else 放前面）

```python
labels = ["小" if n < 3 else "大" for n in nums]
# ['小', '小', '大', '大', '大']
# 注意：if-else三元表达式放在for前面（和过滤的写法位置相反！）
```

## 2. 双层推导：处理嵌套结构

```python
# 把一批句子全部转成小写token
batch = ["Hello World", "Big Model"]
token_batch = [text.lower().split() for text in batch]
# [['hello', 'world'], ['big', 'model']]

# 把嵌套列表拍平
matrix = [[1, 2], [3, 4], [5, 6]]
flat = [x for row in matrix for x in row]    # [1, 2, 3, 4, 5, 6]
# 读法：外层循环在前，内层在后（和两层for的书写顺序一致）
```

## 3. 字典/集合推导式

```python
# 字典推导式
names, sizes = ["gpt", "llama"], [175, 65]
size_map = {n: s for n, s in zip(names, sizes)}       # {'gpt': 175, 'llama': 65}

word2id = {w: i for i, w in enumerate(["我", "爱", "模型"])}
# {'我': 0, '爱': 1, '模型': 2}   —— 造词表的标准写法！

# 集合推导式
unique_lens = {len(w) for w in ["我", "爱", "大模型"]}   # {1, 3}
```

## 4. 常用内置函数速查

### 4.1 聚合类

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(sum(nums))        # 31
print(max(nums))        # 9
print(min(nums))        # 1
print(len(nums))        # 8
print(sum(nums) / len(nums))    # 3.875 均值
```

### 4.2 any / all：存在与全部

```python
losses = [0.5, 0.02, 0.4]
print(any(l < 0.1 for l in losses))    # True   至少有一个<0.1
print(all(l < 1.0 for l in losses))    # True   全部<1.0
```

### 4.3 sorted 的高级用法

```python
words = ["banana", "apple", "kiwi"]
print(sorted(words))                          # 按字母
print(sorted(words, key=len))                 # 按长度 ['kiwi', 'apple', 'banana']
print(sorted(words, key=len, reverse=True))   # 按长度倒序

runs = [("a", 0.3), ("b", 0.1), ("c", 0.2)]
print(sorted(runs, key=lambda r: r[1])[0])    # ('b', 0.1)  找loss最小的实验
```

### 4.4 zip / enumerate / reversed（复习+新用法）

```python
print(list(zip([1, 2, 3], "abc")))    # [(1,'a'), (2,'b'), (3,'c')]
print(list(reversed([1, 2, 3])))      # [3, 2, 1]
```

### 4.5 map / filter（看得懂即可，自己写用推导式）

```python
nums = [1, 2, 3, 4]
print(list(map(lambda x: x * 2, nums)))          # [2, 4, 6, 8]
print(list(filter(lambda x: x > 2, nums)))       # [3, 4]
# 等价推导式（更推荐）：
print([x * 2 for x in nums], [x for x in nums if x > 2])
```

## 5. 生成器表达式：括号一换，内存省亿点

把推导式的 `[]` 换成 `()`，得到**生成器**（第 12 章细讲）：不一次性造出列表，按需一个一个算。

```python
total = sum(x * x for x in range(1_000_000))    # 不用[]，省下100万个数的列表
print(total)
```

经验：**只是中间结果（马上被 sum/max/any 消费）就用 `()`，要反复使用就用 `[]`**。

数据处理管道几乎全是推导式（这是真实的预处理代码风格）：

batch_ids = [[vocab.get(t, 0) for t in text.lower().split()] for text in batch]

# 批量算loss后求均值
avg_loss = sum(batch_losses) / len(batch_losses)

# 找最优超参组合
best = sorted(results, key=lambda r: r["loss"])[0]

## 本章小结

- `[表达式 for x in 序列 if 条件]`——过滤的 if 在后；`a if 条件 else b` 在前
- 字典推导 `{k: v for ...}` 是造词表的标准姿势
- sum/max/min/len/any/all/sorted(key=) 天天用
- 中间结果用生成器表达式 `()`，省内存

## 练习

1. 用一行推导式生成 1~20 中所有偶数的平方。
2. `words = ["transformer", "gpt", "llm", "attention"]`：一行筛出长度≥5的词并转大写。

5. `scores=[0.9, 0.4, 0.95, 0.3, 0.85]`：用 any/all 判断"是否存在>0.9"和"是否全部>0.25"。
