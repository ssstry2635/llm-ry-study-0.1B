# 第 11 章：面向对象编程（类）

> 本章目标：理解"类"和"对象"。**PyTorch 里模型、层、优化器、数据集全是类**——看懂类，PyTorch 代码就看懂了一半。这是全课程最重要的一章。

## 1. 为什么需要类

想表示"一个神经网络层"，它有**数据**（权重 w、偏置 b）也有**行为**（前向计算）。
用零散的变量+函数很乱；**类**把相关的数据和行为打包成一个整体。

- **类（class）**：图纸/模板，比如"线性层"这种东西长什么样
- **对象/实例（instance）**：按图纸造出来的具体东西，比如"第 3 层那个线性层"

## 2. 定义第一个类

```python
class Linear:                          # 类名用大驼峰（首字母大写）
    """一个最简单的线性层: y = w*x + b"""

    def __init__(self, w, b):          # 构造函数：造对象时自动调用
        self.w = w                     # self.w 是实例属性——每个对象自己的数据
        self.b = b

    def forward(self, x):              # 方法：定义在类里的函数，第一个参数永远是self
        return self.w * x + self.b


layer = Linear(2.0, 1.0)               # 造一个实例：自动调用__init__(layer, 2.0, 1.0)
print(layer.w, layer.b)                # 2.0 1.0   访问属性
print(layer.forward(3.0))              # 7.0       调用方法  2*3+1
```

### self 到底是什么

`self` 就是"**这个对象自己**"。调用 `layer.forward(3.0)` 时，Python 自动把 `layer` 塞给 `self`，等价于 `Linear.forward(layer, 3.0)`。
所以方法第一个参数必须写 `self`，但调用时不用传。

`self.w = w` 是"把参数 w 存到这个对象身上"。以后任何方法都能通过 `self.w` 拿到它。

## 3. 类属性 vs 实例属性

```python
class Model:
    count = 0                      # 类属性：所有实例共享

    def __init__(self, name):
        self.name = name           # 实例属性：每个实例独有
        Model.count += 1           # 每造一个就计数

a = Model("gpt")
b = Model("llama")
print(a.name, b.name)              # gpt llama    各自的
print(Model.count)                 # 2            共享的
```

## 4. 魔术方法：让对象"像内置类型一样好用"

双下划线包围的方法（`__xxx__`，读作 dunder）由 Python 在特定时刻自动调用：

```python
class Dataset:
    def __init__(self, samples):
        self.samples = samples

    def __len__(self):                 # len(obj) 时调用
        return len(self.samples)

    def __getitem__(self, idx):        # obj[idx] 时调用
        return self.samples[idx]

    def __repr__(self):                # print(obj) / 交互式环境显示时调用
        return f"Dataset({len(self)}条样本)"


ds = Dataset(["我爱", "大模型", "训练"])
print(len(ds))          # 3          → 调用了 __len__
print(ds[1])            # 大模型      → 调用了 __getitem__
print(ds)               # Dataset(3条样本) → 调用了 __repr__
for s in ds:            # 有__getitem__就能被for遍历！
    print(s)
```

**这正是 PyTorch `Dataset` 的定义方式**：实现 `__len__` 和 `__getitem__`，DataLoader 就能用它。

### `__call__`：让对象能像函数一样被调用

```python
class Linear:
    def __init__(self, w, b):
        self.w, self.b = w, b

    def __call__(self, x):             # obj(x) 时调用
        return self.w * x + self.b

layer = Linear(2.0, 1.0)
print(layer(3.0))                      # 7.0  ← 对象当函数用！
```

**PyTorch 里 `model(x)` 能直接算出结果，靠的就是 `__call__`**（它内部再去调 `forward`）。

## 5. 继承：在别人的基础上改

```python
class Layer:                               # 父类（基类）
    def __init__(self, name):
        self.name = name

    def forward(self, x):
        raise NotImplementedError("子类必须实现forward")   # 逼子类自己写

    def __call__(self, x):
        return self.forward(x)             # 父类统一处理"调用→forward"的逻辑


class ReLU(Layer):                         # 子类：括号里写父类
    def __init__(self):
        super().__init__("relu")           # super() 调父类的__init__，复用它的初始化逻辑

    def forward(self, x):                  # 重写（override）父类方法
        return max(0.0, x)


class Scale(Layer):
    def __init__(self, k):
        super().__init__("scale")
        self.k = k

    def forward(self, x):
        return self.k * x


relu, scale = ReLU(), Scale(10)
print(relu(-3), relu(3))                   # 0.0 3    __call__继承自父类，forward各自实现
print(scale(2))                            # 20
print(isinstance(relu, Layer))             # True     relu也是一个Layer
```

这套结构**就是 `torch.nn.Module` 的精简版**：

```python
# 真实的 PyTorch 代码长这样——现在你完全能读懂它
import torch.nn as nn

class MyModel(nn.Module):                  # 继承 nn.Module
    def __init__(self):
        super().__init__()                 # 必须先调父类init
        self.fc = nn.Linear(768, 10)       # 属性是子层

    def forward(self, x):                  # 只需重写forward
        return self.fc(x)                  # 子层也是对象，直接call

model = MyModel()
out = model(x)                             # __call__ → forward
```

## 6. @property：把方法伪装成属性

```python
class Config:
    def __init__(self, hidden, heads):
        self.hidden = hidden
        self.heads = heads

    @property                               # 装饰器（下章详讲），让方法可以像属性一样不加括号访问
    def head_dim(self):
        return self.hidden // self.heads

cfg = Config(768, 12)
print(cfg.head_dim)                         # 64   注意没有括号
```

适合"由其他属性算出来的量"。

## 7. @dataclass：省掉 `__init__` 的样板代码

配置类只是"装数据"，手写 `__init__` 很啰嗦。`dataclass` 自动生成：

```python
from dataclasses import dataclass

@dataclass
class TrainConfig:
    lr: float = 3e-4               # 字段: 类型 = 默认值
    batch_size: int = 32
    epochs: int = 10
    model_name: str = "mini-gpt"

cfg = TrainConfig(lr=1e-3)         # 自动有__init__
print(cfg)                          # TrainConfig(lr=0.001, batch_size=32, ...)  自动有__repr__
print(cfg.batch_size)               # 32
```

HuggingFace 的 `TrainingArguments`、各种 `ModelConfig` 都是 dataclass。

## 8. 大模型视角 🤖

PyTorch 的世界观 = 一切皆对象：

| 概念 | 是什么类 | 用到的语法 |
|---|---|---|
| 模型/层 | `nn.Module` 子类 | 继承、`__init__`、`forward`、`__call__` |
| 数据集 | `Dataset` 子类 | `__len__`、`__getitem__` |
| 优化器 | `torch.optim.Adam` 实例 | 实例方法 `.step()`、`.zero_grad()` |
| 张量 | `torch.Tensor` 实例 | 属性 `.shape`、方法 `.sum()` |
| 配置 | `@dataclass` | 字段+默认值 |

第 15 章你会用纯 Python 亲手写出 `Linear`、`ReLU`、`MSELoss`、`SGD` 四个类并组装成能训练的网络。

## 本章小结

- `class 名:` 定义；`__init__` 构造；`self` 是对象自己
- 属性存数据，方法定义行为；类属性共享，实例属性独有
- 魔术方法：`__len__`/`__getitem__`（Dataset）、`__call__`（model(x)）、`__repr__`（打印）
- 继承 `class 子(父)` + `super().__init__()`；子类重写 `forward`
- `@property` 算出来的属性；`@dataclass` 省样板

## 练习

1. 定义 `Point` 类，有 x、y 属性和 `distance()` 方法（到原点距离 √(x²+y²)）。
2. 给 `Point` 加 `__repr__`，让 `print(Point(3,4))` 显示 `Point(3, 4)`。
3. 定义 `Tokenizer` 类：`__init__` 接收词表列表并建立 `word2id` 字典；`encode(text)` 把句子按空格切开转 id 列表（未知词给 0）；`__len__` 返回词表大小。
4. 用继承：父类 `Loss` 有 `__call__(pred, target)` 调 `self.compute`；子类 `MSE` 实现 `compute` 返回 `(pred-target)**2`；子类 `MAE` 返回 `abs(pred-target)`。
5. 用 `@dataclass` 定义 `ModelConfig(dim=512, layers=6, vocab=32000)` 并打印。

### 参考答案

```python
import math
from dataclasses import dataclass

# 1 + 2
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def distance(self):
        return math.sqrt(self.x ** 2 + self.y ** 2)
    def __repr__(self):
        return f"Point({self.x}, {self.y})"
p = Point(3, 4)
print(p, p.distance())          # Point(3, 4) 5.0

# 3
class Tokenizer:
    def __init__(self, vocab):
        self.word2id = {w: i + 1 for i, w in enumerate(vocab)}   # 0留给未知词
    def encode(self, text):
        return [self.word2id.get(w, 0) for w in text.split()]
    def __len__(self):
        return len(self.word2id) + 1
tok = Tokenizer(["我", "爱", "大模型"])
print(tok.encode("我 爱 你"), len(tok))   # [1, 2, 0] 4

# 4
class Loss:
    def __call__(self, pred, target):
        return self.compute(pred, target)
class MSE(Loss):
    def compute(self, pred, target):
        return (pred - target) ** 2
class MAE(Loss):
    def compute(self, pred, target):
        return abs(pred - target)
print(MSE()(3, 1), MAE()(3, 1))    # 4 2

# 5
@dataclass
class ModelConfig:
    dim: int = 512
    layers: int = 6
    vocab: int = 32000
print(ModelConfig())
```
