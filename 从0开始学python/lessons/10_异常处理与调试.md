# 第 10 章：异常处理与调试

> 本章目标：学会看懂报错、处理报错、主动报错。**训练跑了 8 小时因为一个没处理的异常崩掉——这一章帮你避免这种惨剧。**

## 1. 先学会读报错（Traceback）

```python
nums = [1, 2, 3]
print(nums[5])
```

运行后：

```
Traceback (most recent call last):
  File "demo.py", line 2, in <module>
    print(nums[5])
IndexError: list index out of range
```

读法（**从最后一行往上读**）：
1. 最后一行 `IndexError: list index out of range` —— 错误类型 + 原因："索引越界"
2. 往上 `File "demo.py", line 2` —— 出错位置：第 2 行
3. 再往上是调用链（函数层层调用的路径），最上面是最外层

90% 的报错，看最后一行 + 定位行号就能解决。看不懂就把最后一行整句复制去搜。

## 2. 常见异常类型一览

| 异常 | 触发场景 | 例子 |
|---|---|---|
| `SyntaxError` | 语法写错 | 少冒号、中文括号 |
| `NameError` | 用了不存在的变量 | 拼写错误 `pritn` |
| `TypeError` | 类型不匹配 | `"a" + 1` |
| `ValueError` | 类型对但值不对 | `int("abc")` |
| `IndexError` | 索引越界 | `[1,2][5]` |
| `KeyError` | 字典里没这个键 | `d["不存在"]` |
| `ZeroDivisionError` | 除以零 | `1/0` |
| `FileNotFoundError` | 文件不存在 | `open("没有.txt")` |
| `ImportError` / `ModuleNotFoundError` | 库没装或名字错 | `import torhc` |
| `AttributeError` | 对象没这个属性/方法 | `"abc".add()` |

看到 `ModuleNotFoundError: No module named 'xxx'` → 去 pip install。这是最常见的报错。

## 3. try / except：接住异常不崩溃

```python
try:
    x = int("abc")             # 这行会抛 ValueError
    print("这行不会执行")
except ValueError:
    print("转换失败，用默认值0")   # 接住后执行这里，程序继续往下走
    x = 0
print("程序没有崩，x =", x)
```

流程：try 里出错 → 立刻跳到匹配的 except → 处理完继续往后走。没出错 → except 被跳过。

### 拿到错误信息

```python
try:
    open("不存在的文件.txt")
except FileNotFoundError as e:      # as e 把异常对象存到e
    print("出错了:", e)              # 出错了: [Errno 2] No such file or directory: ...
```

### 捕获多种异常

```python
def safe_div(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return float("inf")         # 除零返回无穷大
    except TypeError:
        return None                 # 类型错返回None

print(safe_div(1, 0), safe_div(1, "x"))   # inf None

# 或者一个except接多种：
try:
    ...
except (ValueError, TypeError) as e:
    print(e)
```

## 4. else 与 finally

```python
try:
    f = open("data.txt", encoding="utf-8")
except FileNotFoundError:
    print("文件不存在")
else:
    print("打开成功")          # 没出错才执行
    f.close()
finally:
    print("无论如何都执行")     # 常用于清理：关文件、释放显存、保存进度
```

`finally` 是训练脚本的救命稻草：**不管训练正常结束还是崩了，都把 checkpoint 存下来**。

## 5. raise：主动抛出异常

参数不合法时，别默默算出错误结果，要立刻报错：

```python
def set_lr(lr):
    if lr <= 0:
        raise ValueError(f"学习率必须为正数，收到 {lr}")
    print("学习率设置为", lr)

set_lr(0.001)      # 正常
set_lr(-1)         # ValueError: 学习率必须为正数，收到 -1
```

原则："**尽早失败**"（fail fast）——错误越早暴露越容易修。

## 6. assert：断言（调试期的检查点）

```python
batch = [[1, 2, 3], [4, 5, 6]]
assert len(batch) == 2, "batch大小应该是2"       # 条件为假就抛AssertionError并显示消息
assert all(len(row) == 3 for row in batch), "每行长度应该是3"
```

深度学习代码里 `assert x.shape == (batch, seq_len, dim)` 随处可见——**检查张量形状**是 debug 的核心手段。

## 7. 不要这样做

```python
try:
    do_everything()
except:              # ❌ 裸except吞掉所有错误（包括Ctrl+C），出了问题你都不知道
    pass
```

至少写 `except Exception as e: print(e)`，让错误留下痕迹。

## 8. 调试的日常手段

1. **print 大法**：在可疑处 `print(f"{x=}, {type(x)=}, {len(x)=}")`——最快最有效，别看不起它
2. **缩小范围**：把出错的一段单独拿到交互式环境里跑
3. **断点调试**：VS Code 里点行号左侧出现红点 → F5 运行 → 停在断点看变量。第 15 章项目时值得试一下
4. **搜索报错**：复制最后一行去搜，99% 有人踩过

## 9. 大模型视角 🤖

真实训练脚本的容错骨架：

```python
try:
    for epoch in range(epochs):
        train_one_epoch()
except KeyboardInterrupt:              # 你按了 Ctrl+C
    print("手动中断，正在保存...")
except RuntimeError as e:
    if "out of memory" in str(e):      # 显存爆了（CUDA OOM）
        print("显存不足，请减小batch_size")
    else:
        raise                          # 其他错误原样抛出，不要吞
finally:
    save_checkpoint()                  # 无论如何都保存进度
```

- `assert logits.shape == (B, T, V)`：形状不对立刻停，比算出一堆 NaN 再排查省 10 倍时间
- `raise ValueError` 校验超参数：负的学习率、为 0 的 batch_size 直接拒绝

## 本章小结

- 报错从最后一行往上读：类型 + 原因 + 行号
- `try/except 类型 as e` 接住；`else` 成功才做；`finally` 必做（保存进度）
- `raise` 主动报错、`assert` 做检查点；别写裸 `except: pass`
- print 调试是正经手段

## 练习

1. 写 `safe_int(s)`：能转就返回 int，不能就返回 None（`"12"`→12，`"ab"`→None）。
2. 写 `read_or_default(path)`：读文件内容返回字符串，文件不存在返回 `""`。
3. 写 `check_config(cfg)`：cfg 是字典，若缺 `"lr"` 键则 raise KeyError 并带上说明；若 `lr<=0` 则 raise ValueError。
4. 用 assert 检查 `batch=[[1,2],[3,4],[5,6]]` 是"3行2列"。
5. 让下面代码无论是否出错都打印"已保存进度"：`x = 1/0`（提示：finally）。

### 参考答案

```python
# 1
def safe_int(s):
    try:
        return int(s)
    except ValueError:
        return None
print(safe_int("12"), safe_int("ab"))   # 12 None

# 2
def read_or_default(path):
    try:
        with open(path, encoding="utf-8") as f:
            return f.read()
    except FileNotFoundError:
        return ""

# 3
def check_config(cfg):
    if "lr" not in cfg:
        raise KeyError("配置缺少 'lr'")
    if cfg["lr"] <= 0:
        raise ValueError(f"lr 必须为正，收到 {cfg['lr']}")
    return True

# 4
batch = [[1, 2], [3, 4], [5, 6]]
assert len(batch) == 3 and all(len(r) == 2 for r in batch), "应为3行2列"

# 5
try:
    x = 1 / 0
except ZeroDivisionError as e:
    print("出错:", e)
finally:
    print("已保存进度")
```
