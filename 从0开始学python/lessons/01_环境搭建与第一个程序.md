# 第 01 章：环境搭建与第一个程序

> 本章目标：装好环境，运行人生第一行 Python 代码，理解"代码是怎么跑起来的"。

## 1. Python 是什么

Python 是一门**解释型**语言：你写好 `.py` 文本文件，交给 Python 解释器逐行执行，不需要编译。
它是人工智能领域的第一语言——PyTorch、HuggingFace Transformers、几乎所有大模型训练代码都是 Python 写的。

## 2. 确认环境（已帮你装好）

打开终端（Windows 按 `Win + R`，输入 `cmd` 回车；或在文件夹里右键"在终端中打开"），输入：

```
python --version
```

看到类似 `Python 3.11.9` 就说明没问题。本机已确认：**Python 3.11.9**。

> 小知识：`python` 是 3.x 版本。历史上还有 `python2`，早已淘汰，看到老教程用 `print "hello"`（没有括号）直接跳过。

## 3. 两种运行代码的方式

### 方式一：交互式环境（REPL）——草稿纸

终端输入 `python` 回车，出现 `>>>` 提示符，就可以一句一句地试代码：

```
>>> 1 + 1
2
>>> print("你好")
你好
>>> exit()        # 退出
```

特点：敲一句、立刻看到结果，适合做小实验。**学习新语法时强烈推荐先在这里试**。

### 方式二：脚本文件 —— 正式作品

把代码写进 `.py` 文件（比如 `hello.py`），然后：

```
python hello.py
```

正式的训练脚本都是这种方式。

## 4. 第一个程序

新建文件 `hello.py`，写入：

```python
print("Hello, 大模型!")
print("我叫孙ry, 正在从0开始学Python")
```

运行它。`print()` 是"打印"函数：把括号里的内容输出到屏幕。
注意：`print` 后面的括号必须是**英文括号**，字符串两边的引号也必须是**英文引号**。

## 5. 注释：写给人类看的说明

```python
# 井号后面是注释，Python 会完全忽略这一行
print("注释不会被运行")   # 行尾也可以写注释

"""
三个引号包起来的是多行字符串，
当它单独出现时，也常被当作多行注释用。
"""
```

注释是写给**未来的自己和别人**看的。好代码的一半是注释。

## 6. 新手最常见的 3 个错误

1. **中文符号**：`print（"你好"）` 用了中文括号 → 报语法错误。输入法切到英文再敲代码！
2. **文件名起错**：不要把文件命名为 `print.py`、`python.py` 等和内置功能重名的名字。
3. **缩进混乱**：Python 用缩进（行前的空格）表示代码块，现在先记住"每行顶格写"，第 4 章详细讲。

## 7. 大模型视角 🤖

训练大模型的入口脚本（比如你以后会写的 `train.py`），最小形态就是：

```python
# 伪代码，看个眼熟，第15章你能手写出真版
print("开始训练...")
# 加载数据 → 建立模型 → 循环训练 → 保存模型
print("训练完成!")
```

一切复杂系统，都是从 `print` 开始的。

## 本章小结

- `python 文件.py` 运行脚本；敲 `python` 进入交互式环境随手试
- `print(...)` 输出；`#` 写注释
- 代码里的符号全部用英文半角

## 练习（先自己做，答案在最后）

1. 在交互式环境里计算 `123 * 456`。
2. 写一个 `me.py`，用 3 行 print 打印：你的名字、你学 Python 的目的、今天的日期。
3. 给 `me.py` 的每一行加上注释，再运行一次确认注释不影响结果。

---

### 参考答案

```python
# me.py
print("孙ry")                  # 练习2：名字
print("为了训练自己的大模型")    # 练习2：目的
print("2026-09-18")            # 练习2：日期
```

练习1：交互式环境直接输入 `123 * 456` 回车，得 `56088`。
练习3：加 `#` 注释后运行，输出不变——注释只是给人看的。
