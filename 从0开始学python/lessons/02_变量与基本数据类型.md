# 第 02 章：变量与基本数据类型

> 本章目标：理解"变量"这个核心概念，认识 Python 的 5 种基本类型，会做类型转换。

## 1. 变量：给值贴标签

变量 = 给一个值起名字。用 `=` 赋值（读作"赋值为"，不是数学的"等于"）：

```python
name = "GPT"        # 字符串
layers = 12         # 整数
price = 0.001       # 浮点数
print(name, layers, price)   # GPT 12 0.001
```

`name = "GPT"` 的意思是：把字符串 `"GPT"` 存起来，以后用 `name` 这个名字取它。
变量可以随时改指别的值（所以叫"变"量）：

```python
x = 100
x = "一百"     # 完全合法！x 现在是字符串了
```

### 命名规则

- 只能包含字母、数字、下划线，且**不能以数字开头**（`layer_2` ✅，`2layer` ❌）
- 区分大小写：`Loss` 和 `loss` 是两个变量
- 不能用关键字（`if`、`for`、`class` 等被语言占用的词）
- 惯例：用小写+下划线（`learning_rate`、`hidden_size`），这是 Python 世界的通用审美

## 2. 五种基本类型

```python
# 1) int 整数 —— 没有大小限制
vocab_size = 50257          # GPT-2 的词表大小

# 2) float 浮点数（小数）
learning_rate = 0.0003      # 学习率

# 3) str 字符串 —— 引号包起来的文本
model_name = "llama"

# 4) bool 布尔值 —— 只有 True / False 两个值（注意首字母大写）
is_training = True

# 5) NoneType —— 只有 None 一个值，表示"什么都没有/还没定"
best_loss = None            # 还没有最优loss，先占个位
```

## 3. type()：查看类型

```python
print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hi"))       # <class 'str'>
print(type(True))       # <class 'bool'>
print(type(None))       # <class 'NoneType'>
```

Python 是**动态类型**语言：变量自己不用声明类型，赋什么值就是什么类型。

## 4. 类型转换

用 `int()` / `float()` / `str()` / `bool()` 把值从一种类型转成另一种：

```python
print(int("123"))      # 123      字符串 → 整数
print(int(3.99))       # 3        直接砍掉小数（不是四舍五入！）
print(float("0.5"))    # 0.5
print(str(2026))       # "2026"   数字 → 字符串
print(bool(0))         # False    0、空字符串""、None 转 bool 都是 False
print(bool("text"))    # True     其他都是 True
```

什么时候需要转换？——**类型不同不能直接运算**：

```python
age = "18"
# age + 1        # ❌ 报错！str 不能和 int 相加
print(int(age) + 1)   # ✅ 19
```

## 5. input()：接收键盘输入

```python
answer = input("你准备好了吗? ")
print("你输入的是:", answer)     # 注意：input 返回的永远是字符串！
```

如果你输入 `3`，`answer` 是 `"3"`（字符串），要参与计算得先 `int(answer)`。

## 6. 常见坑

1. **浮点数有精度误差**（所有编程语言都有）：

```python
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False ！
```

   原因：计算机用二进制存小数，0.1 在二进制里是无限循环。比较小数是否相等要用 `abs(a-b) < 1e-9` 这种方式。**训练时看 loss 是否下降也一样：别用 `==` 判断。**

2. `None` 不是 `0` 也不是空字符串，它就是"没有"。判断是否为 None 用 `x is None`。

3. 单引号 `'hi'` 和双引号 `"hi"` 完全等价，一个文件里风格统一即可。

## 7. 大模型视角 🤖

- 一个模型本质上是**几十亿个 float 数字**（参数），存在变量里
- 文本被切成的 token 编号是 **int**（如 `[15496, 11, 616]`）
- `is_training=True/False` 这个布尔开关，决定模型是在学习还是只做推理
- `best_loss = None` 这种"先占位、后面再填"的写法在训练脚本里到处都是

## 本章小结

- 变量是名字标签；命名用小写+下划线
- 五种基本类型：int / float / str / bool / None
- `type()` 查类型，`int()` 等做转换，`input()` 收键盘输入
- 浮点数有误差，永远别用 `==` 比较小数
