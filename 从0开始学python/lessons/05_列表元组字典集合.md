# 第 05 章：列表、元组、字典、集合

> 本章目标：掌握 Python 组织数据的四大容器。**大模型代码 80% 的变量是这四种类型**，尤其是列表和字典。

## 0. 总览：一张表看懂四兄弟

| 类型 | 写法 | 特点 | 一句话记忆 |
|---|---|---|---|
| list 列表 | `[1, 2, 3]` | 有序、**可变** | 万能购物袋 |
| tuple 元组 | `(1, 2, 3)` | 有序、**不可变** | 贴了封条的列表 |
| dict 字典 | `{"a": 1}` | 键→值映射、按键取 | 电话簿 |
| set 集合 | `{1, 2, 3}` | 无序、**自动去重** | 不记名的抽奖箱 |

## 1. 列表 list：最重要的容器

### 1.1 创建与取值

```python
tokens = [15496, 11, 616, 9822]     # 一句话的token编号
empty = []                            # 空列表
mixed = ["gpt", 12, 0.5, True]        # 可以混装（但一般别混）

print(tokens[0])       # 15496   索引从0开始
print(tokens[-1])      # 9822    倒数第一个
print(tokens[1:3])     # [11, 616]  切片规则和字符串完全一样！
print(len(tokens))     # 4
print(11 in tokens)    # True    in 判断是否包含
```

### 1.2 增删改

```python
models = ["gpt", "bert"]

models.append("llama")        # 尾部加一个 → ["gpt","bert","llama"]
models.insert(1, "t5")        # 在位置1插入 → ["gpt","t5","bert","llama"]
models[0] = "gpt-4"           # 直接改
models.remove("t5")           # 按值删（只删找到的第一个）
last = models.pop()           # 删掉并返回最后一个 → last="llama"
models.pop(0)                 # 也可以按位置删
```

### 1.3 排序与常用操作

```python
losses = [0.9, 0.2, 0.5, 0.1]

print(sorted(losses))         # [0.1, 0.2, 0.5, 0.9]  返回新列表，原列表不动
losses.sort()                 # 原地排序，无返回
losses.sort(reverse=True)     # 倒着排
print(losses.index(0.5))      # 0.5所在的编号
print(min(losses), max(losses), sum(losses))   # 求最小最大总和
losses.reverse()              # 反转
```

`sorted(x)` vs `x.sort()`：前者返回新列表，后者改原列表。忘了区别就都用 `sorted`。

### 1.4 嵌套：列表的列表 = 矩阵

```python
batch = [[1, 5, 8],           # 第1句话的token
         [2, 9],              # 第2句
         [3, 3, 3, 7]]        # 第3句
print(batch[0])       # [1, 5, 8]      取第1句
print(batch[0][2])    # 8              第1句的第3个token（两层索引）
```

一个 batch 的数据，在结构上就是"嵌套列表"，再进一层就是张量。

## 2. 元组 tuple：不可变的列表

```python
shape = (2, 3)                # 矩阵的形状，天然适合用元组
print(shape[0])               # 2    能查不能改
# shape[0] = 5                # ❌ 报错！元组不可变

# 解包（unpacking）——元组最实用的玩法
rows, cols = shape            # 一次把元组拆给多个变量
a, b = 1, 2
a, b = b, a                   # 经典：交换两个变量不需要中间变量
print(a, b)                   # 2 1
```

函数"返回多个值"其实就是返回元组+解包（第 6 章）。`shape` 这个词记住，张量的 `.shape` 返回的就是元组。

## 3. 字典 dict：键值对（大模型代码的灵魂容器）

### 3.1 基本用法

```python
# tokenizer 的词表就是一个字典：token字符串 → 编号
vocab = {"hello": 15496, ",": 11, "world": 9822}

print(vocab["hello"])          # 15496  按键取值
vocab["!"] = 0                 # 新增
vocab["hello"] = 100           # 修改
print(len(vocab))              # 4
print("world" in vocab)        # True  判断键是否存在（不是判断值！）
del vocab[","]                 # 删除
```

键不存在时直接取会报 KeyError。安全取值用 `.get()`：

```python
print(vocab.get("xxx"))             # None           不存在返回None
print(vocab.get("xxx", -1))         # -1             不存在返回默认值-1
```

### 3.2 遍历三件套

```python
config = {"hidden_size": 768, "layers": 12, "vocab_size": 50257}

for key in config:                  # 默认遍历键
    print(key)

for value in config.values():       # 只遍历值
    print(value)

for key, value in config.items():   # 键值一起遍历（最常用！）
    print(f"{key} = {value}")
```

### 3.3 字典嵌套：模型配置的真实样子

```python
model_config = {
    "name": "mini-gpt",
    "params": {"layers": 6, "dim": 512},
    "tokenizer": {"vocab_size": 32000},
}
print(model_config["params"]["layers"])    # 6  逐层下钻
```

HuggingFace 读进来的 `config.json`、训练脚本的超参数字典，都是这个结构。

## 4. 集合 set：去重专用

```python
tokens = [5, 3, 5, 8, 3, 9, 5]
unique = set(tokens)
print(unique)               # {3, 5, 8, 9}   自动去重（无序！）

a = {1, 2, 3, 4}
b = {3, 4, 5}
print(a & b)                # {3, 4}   交集：都有的
print(a | b)                # {1,2,3,4,5} 并集：合起来去重
print(a - b)                # {1, 2}   差集：a有b没有

print(set("hello"))         # {'h', 'e', 'l', 'o'}  字符去重
```

统计语料里"出现过多少个不同的词"（词表大小）就是 `len(set(words))`。

## 5. 可变 vs 不可变（重要！）

列表、字典、集合是**可变**的（能原地改）；字符串、元组**不可变**（只能造新的）。
这带来一个新手必踩的坑——赋值不复制：

```python
a = [1, 2, 3]
b = a            # b和a指向同一个列表！（不是拷贝）
b.append(4)
print(a)         # [1, 2, 3, 4]  a也"变"了！

c = a.copy()     # 真拷贝要显式copy
c.append(99)
print(a)         # [1, 2, 3, 4]  这次a不动
```

## 6. 大模型视角 🤖

- `tokens: [int]` —— 一条样本
- `batch: [[int]]` —— 一批样本（嵌套列表）
- `vocab: {str: int}` —— 分词器词表
- `config: dict` —— 超参数配置
- `set(tokens)` —— 统计词表/判断OOV
- `shape: tuple` —— 张量形状
- **赋值不拷贝** —— 深度学习里"改了一个变量另一个也变了"的千古 bug 来源

## 本章小结

- 列表：`append/pop/sort/in/索引切片`，全能主力
- 元组：不可变+解包，代表"形状"和"多返回值"
- 字典：`d[key]` 取值、`get` 安全取、`items()` 遍历
- 集合：去重与交并差
- 可变对象的赋值是"贴标签"，拷贝要 `.copy()`

## 练习

1. 建列表 `[5, 3, 8, 1, 9, 2]`：升序排序；取出最大的3个（提示：排序后切片）。
2. 统计字符串 `"abracadabra"` 中每个字母出现的次数，存成字典 `{"a": 5, ...}`。
3. 两个列表 `names=["gpt","llama"]`、`sizes=[175, 65]`，合成字典 `{"gpt": 175, "llama": 65}`（提示：zip + 循环，或字典推导预告）。
4. 用集合判断 `"我爱大模型"` 和 `"大模型爱我"` 是否用了完全相同的字。
5. 踩坑验证：`a=[1,2]`，`b=a`，`b+=[3]`，打印 `a`；再用 `copy()` 重做一遍对比。

### 参考答案

```python
# 1
nums = [5, 3, 8, 1, 9, 2]
nums.sort()
print(nums[-3:])        # [5, 8, 9]

# 2
text = "abracadabra"
counter = {}
for ch in text:
    counter[ch] = counter.get(ch, 0) + 1    # get的默认值用法，背下来！
print(counter)          # {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}

# 3
names, sizes = ["gpt", "llama"], [175, 65]
d = {}
for n, s in zip(names, sizes):
    d[n] = s
print(d)

# 4
print(set("我爱大模型") == set("大模型爱我"))   # True

# 5
a = [1, 2]
b = a
b += [3]
print(a)                # [1, 2, 3]  a被牵连
a2 = [1, 2]
b2 = a2.copy()
b2 += [3]
print(a2)               # [1, 2]    安全
```
