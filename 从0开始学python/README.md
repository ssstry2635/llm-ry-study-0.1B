# 从 0 开始学 Python（面向大模型训练版）

> 目标：**零基础 → 掌握 Python 全部核心语法 → 能看懂并写出训练大模型的代码**。
> 全部学完后，你将无缝衔接上级目录的《从0开始学大模型》课程。

## 课程怎么用（重要，先读这个）

每一章都是三步走，缺一不可：

1. **读讲义**：`lessons/章名.md`，从头读到尾，代码要一行一行看懂；
2. **跑代码**：`code/章名.py`，自己敲一遍再运行（不要复制粘贴，敲的过程就是学习）；
3. **做练习**：讲义末尾的练习题，先自己写，写完再看参考答案。

建议节奏：每天 1~2 章，前 5 章一天两章没问题，后面一天一章。
**做完练习可以把代码发给 AI 助手批改讲解。**

## 学习路线（共 15 章，3 个阶段）

### 第一阶段：基础语法（第 1~5 章）——先会"说话"

| 章节 | 主题 | 学完你能干什么 |
|---|---|---|
| 01 | 环境搭建与第一个程序 | 会运行 Python 代码 |
| 02 | 变量与基本数据类型 | 理解数字、字符串、布尔值 |
| 03 | 运算符与字符串 | 会计算、会处理文本 |
| 04 | 条件与循环 | 会写"重复劳动"的代码 |
| 05 | 列表/元组/字典/集合 | 会组织数据 |

### 第二阶段：进阶核心（第 6~10 章）——会"写文章"

| 章节 | 主题 | 学完你能干什么 |
|---|---|---|
| 06 | 函数 | 会把代码打包复用 |
| 07 | 推导式与内置函数 | 写出简洁地道的 Python |
| 08 | 模块/包/虚拟环境/pip | 会装第三方库（torch 就这么装） |
| 09 | 文件读写与 JSON | 会读写数据集和配置 |
| 10 | 异常处理与调试 | 会看报错、会救场 |

### 第三阶段：面向大模型（第 11~15 章）——为训练模型做好准备

| 章节 | 主题 | 与大模型的关系 |
|---|---|---|
| 11 | 面向对象（类） | PyTorch 的模型就是类，看懂类=看懂一半 PyTorch |
| 12 | 迭代器/生成器/装饰器 | DataLoader 流式喂数据、`@torch.no_grad()` |
| 13 | 类型注解 | 读 HuggingFace/PyTorch 文档和源码必备 |
| 14 | NumPy 速成 | 张量(Tensor)的直系祖先，矩阵运算核心 |
| 15 | 毕业项目 | 纯手写一个会学习的神经网络（不用任何框架） |

## 通关标准

- [ ] 每章练习独立完成
- [ ] 毕业项目：让手写的神经网络 loss 成功下降（纯 Python 版 + NumPy 版）

## 环境说明

- 本机已装好 Python 3.11（终端输入 `python --version` 可验证）
- 第 14 章起需要 numpy：`python -m pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple`
- 编辑器推荐 VS Code（装 "Python" 扩展即可）

## 学完之后

进入上级目录的《从0开始学大模型》——那里才是真正的主线任务。
本课程教的每一个语法点，都会在那条主线里反复出现。
